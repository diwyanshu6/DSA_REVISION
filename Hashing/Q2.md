# Modulo and Remainder Pattern — Interview Revision

## 1. Core Idea

Modulo is useful when the problem contains conditions like:

```text
(a + b) % k == 0
(a - b) % k == 0
subarray_sum % k == 0
```

The general strategy is:

```text
Calculate remainder
        ↓
Find required remainder / matching remainder
        ↓
Use HashMap
```

---

# 2. Count Pairs Whose Sum Is Divisible by `k`

### Condition

```text
(a + b) % k == 0
```

Using modulo:

```text
((a % k) + (b % k)) % k == 0
```

Let:

```text
rem = a % k
```

Then `b` needs:

```text
need = (k - rem) % k
```

### Why `% k` again?

If:

```text
rem = 0
```

then:

```text
k - rem = k
```

But `k` is not a valid remainder. We need `0`.

Therefore:

```python
need = (k - rem) % k
```

### Code

```python
def countPairs(arr, k):
    freq = {}
    count = 0

    for num in arr:
        rem = num % k
        need = (k - rem) % k

        count += freq.get(need, 0)

        freq[rem] = freq.get(rem, 0) + 1

    return count
```

### HashMap

```text
remainder → frequency
```

We store frequency because one current element can form pairs with multiple previous elements.

### Complexity

```text
Time  : O(n)
Space : O(k)
```

# 3. Count Pairs Whose Difference Is Divisible by `k`

### Condition

```text
(a - b) % k == 0
```

This means:

```text
a % k == b % k
```

So we need the **same remainder**.

### Code

```python
def countDifferencePairs(arr, k):
    freq = {}
    count = 0

    for num in arr:
        rem = num % k

        count += freq.get(rem, 0)

        freq[rem] = freq.get(rem, 0) + 1

    return count
```

### Pattern

```text
Sum divisible by k
→ complementary remainder

Difference divisible by k
→ same remainder
```

# 4. Count Pairs Whose Sum Has Remainder `r`

Suppose:

```text
(a + b) % k == r
```

For current remainder `rem`, we need:

```text
(rem + need) % k == r
```

Therefore:

```text
need = (r - rem) % k
```

### Code

```python
def countPairsWithRemainder(arr, k, r):
    freq = {}
    count = 0

    for num in arr:
        rem = num % k
        need = (r - rem) % k

        count += freq.get(need, 0)

        freq[rem] = freq.get(rem, 0) + 1

    return count
```

The normal divisibility problem is simply:

```text
r = 0
```

# 5. Longest Subarray Whose Sum Is Divisible by `k`

This is the important **Prefix Sum + Modulo** variation.

For a subarray `[l ... r]`:

```text
sum(l, r) = prefix[r] - prefix[l - 1]
```

We need:

```text
(prefix[r] - prefix[l - 1]) % k == 0
```

Therefore:

```text
prefix[r] % k == prefix[l - 1] % k
```

## Key Observation

If two prefix sums have the same remainder:

```text
prefix[i] % k == prefix[j] % k
```

then:

```text
(prefix[i] - prefix[j]) % k == 0
```

So the elements between those two prefix positions have a sum divisible by `k`.

---

# 6. What to Store?

For pair problems:

```text
remainder → frequency
```

For longest subarray:

```text
remainder → FIRST INDEX
```

Why first index?

Because we want the longest possible subarray.

Example:

```text
remainder 2 occurs at:

index 1
index 5
index 10
```

If current index is `15`:

```text
15 - 1  = 14  ← longest
15 - 5  = 10
15 - 10 = 5
```

So **never replace the first occurrence**.

---

# 7. Code — Longest Divisible Subarray

```python
def longestSubarray(arr, k):
    prefix = 0

    # remainder → first index
    first = {0: -1}

    ans = 0

    for i, num in enumerate(arr):
        prefix += num
        rem = prefix % k

        if rem in first:
            ans = max(ans, i - first[rem])
        else:
            first[rem] = i

    return ans
```

---

# 8. Why `first = {0: -1}`?

Consider:

```text
arr = [2, 7]
k = 3
```

At index `1`:

```text
prefix = 9
9 % 3 = 0
```

The entire array has sum divisible by `3`.

We need its length:

```text
1 - (-1) = 2
```

Therefore:

```python
first = {0: -1}
```

represents the prefix sum before the array starts.

# 9. Dry Run

```text
arr = [2, 7, 6, 1, 4, 5]
k = 3
```

Prefix sums:

```text
index       0   1   2   3   4   5
value       2   7   6   1   4   5
prefix      2   9  15  16  20  25
remainder   2   0   0   1   2   1
```

Initially:

```text
first = {0: -1}
ans = 0
```

### Index 0

```text
prefix = 2
rem = 2
```

New remainder:

```text
first = {0: -1, 2: 0}
```

### Index 1

```text
prefix = 9
rem = 0
```

`0` already exists at `-1`.

```text
length = 1 - (-1)
       = 2
```

### Index 2

```text
prefix = 15
rem = 0
```

Again `0` exists at `-1`.

```text
length = 2 - (-1)
       = 3
```

### Index 3

```text
prefix = 16
rem = 1
```

New:

```text
first[1] = 3
```

### Index 4

```text
prefix = 20
rem = 2
```

`2` already exists at index `0`.

```text
length = 4 - 0
       = 4
```

Subarray:

```text
[7, 6, 1, 4]
```

Sum:

```text
7 + 6 + 1 + 4 = 18
18 % 3 = 0
```

### Index 5

```text
prefix = 25
rem = 1
```

`1` already exists at index `3`.

```text
length = 5 - 3
       = 2
```

Final answer:

```text
4
```

# 10. Prefix Sum Indexing

There are two valid conventions.

### Convention 1 — Prefix includes current element

```python
prefix += arr[i]
```

Then:

```text
prefix[i] = arr[0] + ... + arr[i]
```

If the same remainder occurs at indices `j` and `i`:

```text
subarray = arr[j + 1 ... i]

length = i - j
```

This is the convention used above.

### Convention 2 — Prefix stores number of elements

```python
prefix = [0]
```

where:

```text
prefix[i] = sum of first i elements
```

Then:

```text
sum(l, r) = prefix[r + 1] - prefix[l]
```

Both are correct. The important thing is to remain consistent.

# 11. Quick Revision Table

| Problem                         | What to search        | HashMap stores |
| ------------------------------- | --------------------- | -------------- |
| `(a+b) % k == 0`                | `(k-rem) % k`         | Frequency      |
| `(a-b) % k == 0`                | `rem`                 | Frequency      |
| `(a+b) % k == r`                | `(r-rem) % k`         | Frequency      |
| Longest subarray sum `% k == 0` | Same prefix remainder | First index    |

# 12. Core Formulas to Remember

### Pair Sum

```text
rem = num % k
need = (k - rem) % k
```

### Pair Difference

```text
rem = num % k
need = rem
```

### Pair Sum With Target Remainder

```text
rem = num % k
need = (r - rem) % k
```

### Longest Divisible Subarray

```text
prefix[r] - prefix[l - 1]
```

If:

```text
prefix[r] % k == prefix[l - 1] % k
```

then:

```text
subarray sum % k == 0
```

Store:

```text
remainder → first index
```

and maximize:

```text
current_index - first_index
```

# 13. The Pattern

```text
Modulo Problem
      ↓
Calculate remainder
      ↓
Determine relationship between remainders
      ↓
HashMap
      ↓
Frequency OR First Index
```

### Remember

```text
PAIR
→ count how many
→ frequency

LONGEST SUBARRAY
→ maximize distance
→ first index
```

The most important mathematical observation is:

```text
Same prefix remainder
        ↓
Difference of prefix sums is divisible by k
        ↓
Subarray sum is divisible by k
```
