# 📌 Valid Anagram

🔗 **Problem:** https://leetcode.com/problems/valid-anagram/

## Approach 1: Sorting (Brute Force)

### Idea
Sort both strings and compare them.

### Complexity

- **Time:** `O(n log n)`
- **Space:** `O(1)` (Ignoring sorting space)

```python
return sorted(s) == sorted(t)
```

---

## Approach 2: Two HashMaps

Store frequency of every character in both strings.

```text
Map1 -> Frequency of s
Map2 -> Frequency of t

If both maps are equal
    return True
Else
    return False
```

### Complexity

- Time: `O(n)`
- Space: `O(26)` (English lowercase letters)

---

## Approach 3: One HashMap (Best)

### Idea

1. Increase frequency for characters of first string.
2. Decrease frequency while traversing second string.
3. If any frequency becomes negative → Not an Anagram.

```text
for ch in s
    freq[ch]++

for ch in t
    freq[ch]--
    if freq[ch] < 0
        return False

return True
```

### Complexity

- Time: `O(n)`
- Space: `O(26)`

# ⭐ Important HashMap Patterns

---

# Pattern 1 — Find Duplicate Element Within Distance K

### Problem

Check if two equal numbers exist whose distance is **≤ k**.

Example

```text
nums = [1,2,3,1]
k = 3

Answer = True
```

---

## 💡 Intuition

We only care about the **last occurrence** of every element.

Store

```text
Element -> Last Index
```

Whenever we see the same element again

```text
distance = currentIndex - lastIndex

If distance <= k
    return True
```

Update last index every time.

---

## Complexity

- Time: `O(n)`
- Space: `O(n)`

---

# Pattern 2 — Check if One Array is a Subset of Another

### Problem

Determine whether every element of one array exists in another.

Duplicates matter.

---

## 💡 Intuition

Store frequencies of the larger array.

```text
Element -> Frequency
```

Now iterate through subset array.

If

```text
frequency[element] == 0

return False
```

Else

```text
frequency[element]--
```

If traversal completes

```text
return True
```

---

## Complexity

- Time: `O(n+m)`
- Space: `O(n)`

---

# Pattern 3 — Count "LC" Subsequences

Example

```text
LCLLC
```

Need to count all subsequences

```text
LC
```

---

## 💡 Intuition

Every **C** asks:

> "How many L's appeared before me?"

Every previous **L** forms one valid subsequence.

So,

```text
Answer += Number of L before current C
```

---

### Example

```text
L C L L C

L count = 1

First C
Answer += 1

L count = 3

Second C
Answer += 3

Total = 4
```

---

## Pattern

```text
Maintain

countL

Whenever

L

countL++

Whenever

C

answer += countL
```

---

## Complexity

- Time: `O(n)`
- Space: `O(1)`

---

# Pattern 4 — Count Pairs with Sum = K

Condition

```text
arr[i] + arr[j] = K

i < j
```

---

## 💡 Intuition

At every element

```text
x
```

We need

```text
K - x
```

If complement already exists,

every occurrence forms one pair.

---

## Pattern

```text
answer += frequency[K-current]

frequency[current]++
```

---

## Complexity

- Time: `O(n)`
- Space: `O(n)`

---

# Pattern 5 — Count Pairs with Difference = K

Condition

```text
arr[i]-arr[j]=K

i<j
```

---

## Formula

Current element

```text
x
```

Need previous element

```text
x+k
```

So

```text
answer += frequency[x+k]

frequency[x]++
```

---

## Complexity

- Time: `O(n)`
- Space: `O(n)`

---

# Pattern 6 — Count Pairs with Absolute Difference = K

Condition

```text
|arr[i]-arr[j]| = K
```

---

## Two Possibilities

```text
arr[i]=arr[j]+K
```

OR

```text
arr[i]=arr[j]-K
```

Therefore,

```text
answer += frequency[current-k]

answer += frequency[current+k]
```

Then update frequency.

---

## Complexity

- Time: `O(n)`
- Space: `O(n)`

# Pattern 7 — Range Sum Query

Need

```text
Sum from index l to r
```

---

## Prefix Array

```text
prefix[i]
=
arr[0]+arr[1]+...+arr[i]
```

---

## Formula

```text
Sum(l,r)

=

prefix[r]-prefix[l-1]
```

Special case

```text
l==0

Answer = prefix[r]
```

---

## Complexity

Preprocessing

```text
O(n)
```

Every Query

```text
O(1)
```

# Pattern 8 — Count Subarrays with Sum = K ⭐⭐⭐

This is one of the most important HashMap patterns.

---

## 💡 Intuition

Suppose

```text
prefixSum = currentSum
```

Need subarray

```text
currentSum - previousPrefix = K
```

Therefore

```text
previousPrefix

=

currentSum-K
```

If this prefix has appeared multiple times,

each occurrence forms one valid subarray.

---

## Pattern

```python
from collections import defaultdict

def count_subarrays(arr, k):

    prefix = defaultdict(int)
    prefix[0] = 1

    curr = 0
    ans = 0

    for x in arr:

        curr += x

        ans += prefix[curr-k]

        prefix[curr] += 1

    return ans
```

---

## Complexity

- Time: `O(n)`
- Space: `O(n)`

---

# Pattern 9 — Largest / Smallest Subarray with Sum = K

Need

```text
Maximum Length

OR

Minimum Length
```

such that

```text
Subarray Sum = K
```

---

## 💡 Intuition

For every prefix sum

```text
curr
```

Need

```text
curr-k
```

If it already exists,

subarray exists.

Length

```text
currentIndex
-
storedIndex
```

Update answer.

---

## Important Observation

For

### Largest Length

Store the **first occurrence** of every prefix sum.

For

### Smallest Length

Store the **latest occurrence**.

---

## Complexity

- Time: `O(n)`
- Space: `O(n)`

# 🎯 Recognizing HashMap Problems

Whenever you hear...

| Problem Statement | Pattern |
|-------------------|----------|
| Frequency counting | HashMap |
| Duplicates | HashMap |
| Pair Sum | Complement |
| Pair Difference | Required Value |
| Subarray Sum | Prefix Sum + HashMap |
| Longest/Smallest Subarray | Prefix Sum + First/Last Occurrence |
| Range Sum Queries | Prefix Array |
| Count Subsequences | Running Count |

---

# 🚀 HashMap Cheat Sheet

## Frequency Map

```python
freq = {}

for x in arr:
    freq[x] = freq.get(x, 0) + 1
```

---

## Last Occurrence

```python
last = {}

for i, x in enumerate(arr):
    if x in last:
        # Process
        pass

    last[x] = i
```

---

## Prefix Sum

```python
prefix = 0

for x in arr:
    prefix += x
```

---

## Prefix Sum + HashMap

```python
mp = {0:1}

prefix = 0

for x in arr:

    prefix += x

    answer += mp.get(prefix-k, 0)

    mp[prefix] = mp.get(prefix, 0) + 1
```

# 🧩 Mental Checklist During Interviews

Whenever you see a problem, ask yourself:

- ✅ Can I store **frequency**?
- ✅ Can I store the **last occurrence**?
- ✅ Can I transform it into a **complement search**?
- ✅ Can I use a **prefix sum**?
- ✅ Can I convert nested loops into a **HashMap lookup**?

If the answer is **Yes**, there is usually an **O(n)** solution.
